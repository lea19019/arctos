# papers

PDFs referenced by the `compression/` and `speech-translation/` tracks. Named
bibliographically so they sort by author/topic rather than by the repo's
`lower_case_with_underscores` convention.

- `pruning_project.pdf` — *Interpretability-Guided Layer Pruning for Efficient
  Multilingual Machine Translation* (Castillo & Richardson, BYU). The prior work
  this project builds on: IFR layer scoring → pruning → LoRA/KD recovery → GPTQ,
  on Aya Expanse 8B.
- `mmmc_multilingual_corpus.pdf` — *MMMC: A Massively Multi-way-aligned
  Multilingual Corpus*.

The `interlingua/` track keeps its own, much larger bibliography of PDFs in
[`../../interlingua/papers/`](../../interlingua/papers/).
