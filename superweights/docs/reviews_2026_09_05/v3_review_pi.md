# PI review of proposal v3 (whole-document, coherence and scope) — 2026-09-05

## (a) Verdict: SURVIVES WITH CHANGES — but not as v3 alone. Merge v3 §1–2 onto v2's method.

v3 fixes v2's real weakness (the MT link was decorative) and creates a worse one: it is three projects sharing a model. The title asks Problem 1's question only; Arm B answers a different question on a different failure mode whose resource gradient runs the *opposite* way (Guerreiro: oscillatory hallucinations are *less* frequent in low-resource directions); Arm C is v2 demoted to "instrument", with every mechanistic item moved to weeks 13–15 "as time allows". If Arm A returns "sink handling changes nothing" and Arm B "nothing beyond log-probability" — both plausible, and the brief says to treat them as results — the report is two clean negatives about a phenomenon the student never characterised, because the characterisation was the optional part. v2 had a thesis in every outcome; v3 has one only if Arm C runs. So make Arm C mandatory and first, keep one intervention arm behind a gate, and drop the other.

## (b) Objections

1. **The fallback destroys Arm A.** §6: "if it slips, Arm A runs on weight-only quantization first and the sink-exemption condition is the stretch." Sink-token exemption is an *activation*-quantization operation; under weight-only quantization there is no intervention left, and the registry already has that experiment: `rtn+SW ≈ rtn` on 8 models, and the uneven-PTQ table. The fallback re-runs a known negative and calls it Arm A. Fix: a week-3 go/no-go on a fake-quant W8A8 path (none exists in `compression/src/quant/` — only AWQ/BnB/GGUF/AutoRound); no path, no Arm A.

2. **At the bit-width that is feasible the problem may not exist.** Marie & Fujita's 17-point gaps are at 2-bit; W8A8 SmoothQuant is near-lossless in English. Per-language COMET deltas at W8A8 will be fractions of a point against sentence-bootstrap CIs of about ±0.5. H1 is then undecidable, not false. Fix: pre-register a minimum detectable gap and pilot one model, three languages, before committing 55 h.

3. **H1(a) contradicts the phenomenon literature v3 itself cites.** §2: "quantization error at the sink token distorts the constant every position reads." Sun Table 3 / Owen Table 1: the constant's *value* is irrelevant (set-to-mean harmless). What the outlier-quant papers actually describe is the massive channel wrecking per-channel/per-tensor *scales for every other token* — a different mechanism with a different language dependence. Restate (a) as scale contamination, or the intervention tests the wrong hypothesis.

4. **Arm B's chain of inference breaks twice.** §2: lesioned-model loops → oscillatory hallucination → sink statistics in a *healthy* NLLB. (i) A universal loop from a broken model is not an input-conditional failure of a working one (the MT reviewer said this of v2; v3 kept the chain). (ii) HalOmi's outputs were decoded with 4-gram repetition *blocked* (HalOmi §3: "forbidden repetition of 4-grams"), so the repetition link cannot be tested on the only benchmark Arm B uses. What remains is Binkowski's SinkProbe ported to NLLB — legitimate, but a probing exercise with no mechanism, and §1's "Nothing in this literature looks inside the model at outlier structure" is contradicted by §2's own Binkowski citation.

5. **Six fixes from the earlier reviews were dropped.** Kept: contribution-mean control, magnitude-matched null (max of 50), dose sweep, position-split ablation. Dropped: attention-mask sink dissociation (BOS-drop was removed but replaced with nothing); NLLB `</s>` at position 0 / tag at position 1 (v3 says only "the decoder's first positions"); "undecidable, not inert" at the null ceiling; the model's-own-unigram null for the repeated-token test (§5 correlates against "each language's unigram distribution" only — the novelty review's objection 5 returns intact); frozen-final-norm and KL-to-unigram; and the coverage statement on the collapse claim.

6. **Budget.** The methods reviewer priced v2 at 165–200 h. v3 adds a W8A8 path with sink exemption and calibration crossing (≥20 h), 20 FLORES directions × 3 models × ~11 conditions × n≈960 with COMET (hundreds of GPU-hours, plus the pipeline: the lab's protocol is WMT24++ on 6 languages with chat templates, which NLLB does not take), and HalOmi teacher-forcing hooks on an encoder-decoder (≥20 h). Honest total: 200–240 h. Arm C at 25 h for six models × three conditions × two granularities × dose sweep with per-language metrics is thin by half.

7. **Claim hygiene (CLAUDE.md rules 2, 3, 4).** "Generation after ablation collapses into repeated function words" (§3) — coverage gone; v2 said "two models, one prompt, greedy". "The output of a model whose constant is removed is a loop of function words" (§2) — weight-zeroing is not constant removal (Yu: restoring the constant recovers 42%). "My lab replicated the effect for English-to-X translation" (§1) — true, and omits that X→en did *not* replicate (registry C2), while Arm A runs X→en. "compare to sequence log-probability… as reported by Dale et al. (2023a)" (§5) — a baseline not measured, from a different dataset; HalOmi's baselines are in 2023b and Seq-Logprob must be recomputed on the same run. "the only known mitigation, language-matched calibration" (§1) — the registry's own "MT calibration does not help AWQ" contradicts "mitigation".

## (c) Cut, keep, sharpen

**Cut:** Arm B as an arm (one paragraph as a stretch instrument, per the paper-notes verdict "adopt as instrument, reject as headline"); NLLB-3.3B from Arm A; 20 directions → 8–10 (FLORES, en→X only, since X→en did not replicate). **Keep:** §1–2 as motivation for Problem 1; the instrument table with its three controls; the dose sweep. **Sharpen:** Arm C becomes weeks 3–8 and non-optional, restored to v2 §4 content (position split, attention-mask dissociation, unigram null with the model-global baseline, `</s>`-vs-tag on NLLB); Arm A becomes a single gated experiment — two models, W8A8 ± sink exemption × two calibration sets — with a pre-registered minimum detectable gap; deliverables regain v2's "mechanistic account per model". Title: v3's if Arm A passes the gate, v2's otherwise.

## (d)

**Most decidable:** Arm C's per-model criticality of the whole neuron against the magnitude-matched null — existing tooling, forward passes, yes/no/undecidable per model. **Least decidable:** H1's (a)-versus-(b) discrimination — an interaction in a 2×2 at W8A8, where the main effect may sit below the CI floor, on n=20 languages collinear in script and resource.
